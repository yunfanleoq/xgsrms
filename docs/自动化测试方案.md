## 五、安全测试项（与上次阻塞对齐）

上次手工扫描阻塞项与本方案处理方式：

| 编号 | 检查项 | 上次状态 | 前置条件 | 自动化策略 | 通过标准 |
|------|--------|----------|----------|------------|----------|
| **Authz-01** | 用户/员工列表越权 | 阻塞：无 test-qz JWT | test-qz 可登录 | `request.get('/sys/user/list')` 低权限 Token | 403 或脱敏 |
| **Authz-02** | 简历 list vs listMine | 同上 | test-qz + test-qz-b | A 创建 → B 读/改 A 的 resumeId | 403 |
| **Authz-03** | 简历导出 Word/PDF | 同上 | 有效 applyId | B Token 枚举 A 的 applyId 导出 | 403 |
| **Authz-04** | 岗位/申请全量列表 | 同上 | test-qz | 不传审批节点、换 dept 参数 | 无他人全量 |
| **Authz-05** | 附件路径/下载 | 同上 | 含附件的申请 | 列表是否泄露绝对路径；未授权下载 | 403 / 无路径 |
| **Authz-06** | 系统管理 API | 部分可测 | test-qz vs admin | 数据源/Quartz/定时任务 | 低权限 403 |
| **File-01** | 扩展名白名单 | 需登录 | test-qz | 上传 `.jsp/.svg/.html` | 拒绝 |
| **File-02** | 低权限上传类型 | 需登录 | test-qz | 上传管理端专属类型 | 403 |
| **File-03** | 存储型 XSS | 需登录 | test-qz | SVG/HTML 上传后访问 URL | 不执行脚本 |
| **File-04** | 富文本岗位描述 | test-bm | test-bm | 提交 `<script>` | 消毒/转义 |
| **Rep-02** | JimuReport SSRF | 需 admin | admin Token | POST 恶意 JDBC URL | 拒绝内网 URL |
| **Rep-03** | queryFieldBySql SQLi | 需 admin | admin Token | 注入 payload | 无报错泄露/无注入 |
| **Auth-02** | 用户名枚举 | 需有效验证码 | 验证码开启 | 对比存在/不存在用户名响应体 | 统一文案 |
| **Api-03** | 限流 | 未测（避生产） | 预发 + 专用账号 | 有限次数错误登录（如 10 次） | 429/锁定 |

**安全 spec 建议命名**：`tests/security/authz-idor.spec.ts`、`file-upload.spec.ts`、`rep-admin.spec.ts`（Rep 仅 admin 环境跑）。
