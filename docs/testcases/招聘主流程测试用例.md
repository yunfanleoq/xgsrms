# 招聘主流程测试用例

| 项目 | 说明 |
|------|------|
| 环境 | `https://10.28.12.15`（需 VPN） |
| 关联计划 | [招聘主流程测试计划.md](招聘主流程测试计划.md) |
| E2E | `jeecgboot-vue3/tests/e2e/flows/recruitment-full-chain.spec.ts` |
| 账号 | `test-qz`（应聘者）/ `test-bm`（部门）/ `test-rl`（人事处） |

---

## TC-APPLY — 应聘者投递

| 项 | 内容 |
|----|------|
| 编号 | TC-APPLY |
| 前置 | `test-qz` 可登录；存在**未投递**的在招岗位（若全部已投递则本步 skip，在报告标注） |
| 账号 | `test-qz` |
| 步骤 | 1. 打开 `/home/positions`，进入岗位详情<br>2. 点击【在线申请】<br>3. 核对基本信息 / 教育 / 工作 / 登记照 / 附件后【提交申请】 |
| 期望 | 提示成功；按钮变为「岗位已申请」；【我的申请】出现对应岗位记录 |

---

## TC-HR-COLLECT — 人力处收集

| 项 | 内容 |
|----|------|
| 编号 | TC-HR-COLLECT |
| 前置 | TC-APPLY 成功，或列表已有待收集记录 |
| 账号 | `test-rl` |
| 步骤 | 1. 【简历审核管理】→【人力处收集】<br>2. 定位目标岗位/申请人<br>3. 【审核】→【同意】 |
| 期望 | 记录离开收集池；流转至部门审核待办 |

---

## TC-DEPT — 部门审核

| 项 | 内容 |
|----|------|
| 编号 | TC-DEPT |
| 前置 | TC-HR-COLLECT 通过 |
| 账号 | `test-bm`（须为本岗位所属部门） |
| 步骤 | 1. 【简历审核管理】→【部门审核】<br>2. 定位记录 →【审核】→【通过】 |
| 期望 | 通过后进入人力处审核待办；其他部门账号不可见（数据权限） |

---

## TC-HR-FINAL — 人力处审核

| 项 | 内容 |
|----|------|
| 编号 | TC-HR-FINAL |
| 前置 | TC-DEPT 通过 |
| 账号 | `test-rl` |
| 步骤 | 1. 【简历审核管理】→【人力处审核】<br>2. 【审核】→【通过】 |
| 期望 | 终审通过；候选人出现在面试邀请池 |

---

## TC-INVITE — 面试邀请

| 项 | 内容 |
|----|------|
| 编号 | TC-INVITE |
| 前置 | TC-HR-FINAL 通过 |
| 账号 | `test-rl` |
| 步骤 | 1. 【面试管理】→【面试邀请】<br>2. 对目标记录【发送面试邀请】，填写时间、地点、说明 →【执行】 |
| 期望 | 邀请状态变为已发送；应聘者【我的面试】可见 |

---

## TC-ACCEPT — 应聘者接受邀请

| 项 | 内容 |
|----|------|
| 编号 | TC-ACCEPT |
| 前置 | TC-INVITE 成功 |
| 账号 | `test-qz` |
| 步骤 | 1. 【个人中心】→【我的面试】<br>2. 对目标岗位【接受邀请】 |
| 期望 | 接受成功；人事侧可录入面试结果 |

---

## TC-RESULT — 面试结果（通过 / 未通过）

| 项 | 内容 |
|----|------|
| 编号 | TC-RESULT |
| 前置 | TC-ACCEPT 成功 |
| 账号 | `test-rl` |
| 步骤 | 1. 【面试管理】→【面试邀请】（或招聘智能体工作流「面试」阶段）<br>2. 对已接受记录点击【面试通过】或【面试未通过】并确认 |
| 期望 | `interviewResult` 显示「面试通过」或「面试未通过」；结论不可再改；应聘者端展示一致 |

**用例变体：**

- TC-RESULT-PASS：录入通过
- TC-RESULT-FAIL：录入未通过（可用另一条申请或第二次跑，勿与 PASS 争同一结论）
