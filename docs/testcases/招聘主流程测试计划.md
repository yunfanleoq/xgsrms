# 招聘主流程测试计划

## 1. 目标

在正式环境验证三角色主链路：**投递 → 人力处收集 → 部门审核 → 人力处审核 → 面试邀请 → 接受 → 面试结果**，并产出带截图的测试报告（HTML + PDF）。

## 2. 环境与准入

| 项 | 值 |
|----|-----|
| 基址 | `https://10.28.12.15` |
| 网络 | 本机须已登录 aTrust VPN（本地登录）；云端 Agent 通常**无法**直连 |
| 前端 API | 正式包 `VITE_GLOB_API_URL=/xgszp-boot` |
| 账号 | `test-qz` / `test-bm` / `test-rl`（口令见本机 `.env.e2e` 或钥匙串，**勿入库**） |

准入检查：

1. 浏览器可打开首页并登录三角色（验证码可用 OCR / 手工）。
2. 门户至少有一个可投递岗位；若均已投递：跳过 TC-APPLY，从现有申请继续，报告标注 `skip`。
3. 弱口令策略若强制改密：用 admin 重置或按策略改密后记入报告。

## 3. 数据策略

- **优先**选用 `test-qz` **尚未投递**的岗位。
- 已投递：E2E `alreadyApplied` / 步骤 `skip`，不造假「投递成功」。
- 面试结果：同一次全链路默认跑 **TC-RESULT-PASS**；未通过变体单独安排，避免覆盖同一结论。
- 不在生产批量压测登录；不刷验证码接口。

## 4. 执行步骤（本机 VPN）

```bash
cd jeecgboot-vue3
# 配置 .env.e2e：E2E_BASE_URL=https://10.28.12.15 及三角色账号
pnpm exec playwright test tests/e2e/setup   # 或项目约定的 OCR 登录 setup
E2E_RUN_ID=prod-$(date +%Y%m%d-%H%M) pnpm exec playwright test tests/e2e/flows/recruitment-full-chain.spec.ts

# 从 manifest 生成 HTML（已有）与 PDF
python3 scripts/generate_e2e_report_and_manual.py --run-dir docs/e2e-runs/$E2E_RUN_ID
python3 scripts/generate_e2e_pdf_report.py --run-dir docs/e2e-runs/$E2E_RUN_ID
```

产物：

- `docs/e2e-runs/<runId>/manifest.json`
- `docs/e2e-runs/<runId>/测试报告.html`
- `docs/e2e-runs/<runId>/招聘主流程测试报告.pdf`

## 5. 用例范围

见 [招聘主流程测试用例.md](招聘主流程测试用例.md)：TC-APPLY … TC-RESULT。

## 6. 通过准则

- 无 `fail` 步骤；`skip` 须写明原因（已投递 / 列表无行等）。
- PDF 报告含逐步截图与操作说明。
- **禁止**在未连通正式环境时伪造「实测通过」。

## 7. 云端 / 无 VPN 说明

Cursor Origin 云端 worktree **通常访问不到** `10.28.12.15`。该情况下：

- 交付用例文档 + PDF 生成脚本即可；
- PR / 说明中标注：**需本机 VPN 跑 Playwright**；
- 阶段 C 实测状态记为 **阻塞（网络）**，不以空转重试 VPN 冒充完成。
