# 开发指南

← [[00-Index]]

## 环境准备

| 工具 | 版本 |
|------|------|
| JDK | 17（脚本可指向 `Microsoft jdk-17`） |
| Maven | 3.8+ |
| Node | 20.19+ 或 22.12+ |
| pnpm | 9+ |
| MySQL | 5.7+ |
| Redis | 可选 |

## 本地启动

### 方式 A：批处理（Windows）

```text
start-all.bat   # 交互：库初始化 / 后端 / 前端
```

### 方式 B：手动

```powershell
# 数据库：init-database.bat 或导入 SQL

# 后端
Set-Location I:\cursorProjects\xgsrms\jeecg-boot
mvn -pl jeecg-module-system/jeecg-system-start -am spring-boot:run

# 前端
Set-Location I:\cursorProjects\xgsrms\jeecgboot-vue3
pnpm install
pnpm dev
```

访问见 [[01-项目总览]]。

## 新增业务功能（推荐流程）

1. **表设计** → MySQL
2. **代码生成**（Jeecg Online 或代码生成器）→ 生成到 `jeecg-module-recruitment` 或独立子包
3. **前端** `views/xgs*` + `*.api.ts` + 菜单 SQL
4. **权限** 配置按钮码 + 数据权限规则
5. **Shiro** 若需匿名访问，**显式**加入 `ShiroConfig`（慎用以 [[09-安全与扫描]] 为准）
6. **文档** 更新 [[05-后端API清单]]、[[06-前端页面映射]]

## 升级 JeecgBoot

官方 3.7 → 3.9 见：

- `docs/UPGRADE-JeecgBoot-3.9.md`
- `scripts/upgrade-to-jeecg391.ps1`

升级后合并 `application-*.yml` 与招聘模块 `javax` → `jakarta`。

## 常用命令

```powershell
# 仅打包后端
mvn -pl jeecg-module-system/jeecg-system-start -am package -DskipTests

# 前端 E2E
pnpm test:e2e

# 手册 Word
pip install -r scripts/requirements-manual-docx.txt
python scripts/md_to_docx_manual.py
```

## IDE 建议

- 后端：IDEA，导入 `jeecg-boot` 为 Maven 工程
- 前端：VS Code / WebStorm，TypeScript 严格模式
- 联调：浏览器 DevTools Network 看 `X-Access-Token` 与签名头

## 代码规范

- 遵循仓库既有 Jeecg 分层；单文件超 500 行考虑拆分 Service
- 不提交密钥、`.env` 生产配置、`local-signature.env`
- 推送前仅在用户要求时 `git push` 双远端
