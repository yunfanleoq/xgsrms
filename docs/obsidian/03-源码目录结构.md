# 源码目录结构

← [[00-Index]]

## 仓库根目录

```
xgsrms/
├── jeecg-boot/                 # 后端
├── jeecgboot-vue3/             # 前端
├── jeecg-uniapp/               # 移动端（可选）
├── docs/                       # 文档（含本 obsidian 库）
├── scripts/                    # 构建/部署/安全脚本
├── start-*.bat                 # Windows 本地启动
└── README.md / README-RUN.md
```

## 招聘模块后端包结构

路径：`jeecg-boot/jeecg-module-recruitment/src/main/java/org/jeecg/modules/recruitment/`

| 包 | 职责 |
|----|------|
| `positions/` | 岗位发布、收藏、岗位申请 `XgsPositionApply` |
| `position/` | 流程意见 `XgsFlowOpinions` |
| `xgsResume/` | 多类型简历（PT/FG/TJ/BSH 等） |
| `xgsMyresume/` | 求职者「我的简历」聚合 |
| `resume/` | 简历附件、解析 `XgsUserResumeFile` |
| `xgsHome/` | 门户首页内容配置 |
| `xgsJournalism/` | 新闻/科研发展 |
| `xgsIntroduce/` | 研究所介绍 |
| `xgsContactUs/` | 联系我们 |
| `xgsInterview/` | 面试记录 |
| `xgsInviteToInterview/` | 面试邀请 |
| `xgsTalentpool/` | 人才库 |
| `xgsExport/` | 简历导出 |

每个业务包典型分层：

```
controller/  → REST，@RequestMapping
service/     → 业务逻辑
mapper/      → MyBatis 接口
mapper/xml/  → SQL
entity/      → 表映射
vo/          → 前后端传输对象
```

## 前端视图目录（招聘相关）

路径：`jeecgboot-vue3/src/views/`

| 目录 | 说明 |
|------|------|
| `home/` | 对外门户（岗位列表、详情、新闻） |
| `xgsApplyForm/` | 在线申请表单 |
| `xgsMyresume/` | 我的简历 |
| `xgsRecruitment/` | 招聘管理 |
| `postionsPost/` | 岗位发布（注意拼写 postions） |
| `positions/` | 岗位与申请 |
| `positionsCheck/` | 岗位审核 |
| `xgsApplyCheck/` | 申请检查 |
| `xgsApplyVerify/` | 部门/人力 审核（dep_verify / rcl_verify） |
| `xgsResumeApproval/` | 简历审批 |
| `xgsResumeBase/` | 简历库（按类型分子目录） |
| `xgsInviteToInterview/` | 面试邀请 |
| `xgsMyInterview/` | 我的面试 |
| `xgsTalentpool/` | 人才库 |
| `xgsHome` / `xgsJournalism` / `xgsContactUs` / `xgsIntroduce` | 内容管理 |

路由与菜单：动态菜单来自后端；固定门户见 `src/router/routes/index.ts` 中 `homeIndexRoute`。

## 配置与 SQL 热点

| 路径 | 内容 |
|------|------|
| `jeecg-system-start/.../application-*.yml` | 数据源、Redis、签名密钥 |
| `jeecg-system-start/.../flyway/sql/mysql/` | 库表迁移 |
| `scripts/sql/mysql/` | 权限补丁 SQL |
| `jeecg-boot-base-core/.../ShiroConfig.java` | 匿名 URL 链 |

## 实体与表（核心）

| Entity | 业务含义 |
|--------|----------|
| `XgsPositions` | 招聘岗位 |
| `XgsPositionApply` | 岗位申请/投递主表 |
| `XgsResumeBase` / `FG` / `TJ` / `BSH` | 分类型简历 |
| `XgsFlowOpinions` | 审核流转意见 |
| `XgsInterview` | 面试 |
| `XgsInviteToInterview` | 面试邀请 |
| `XgsTalentpool` | 人才库 |
| `XgsUserResumeFile` | 上传简历文件 |
