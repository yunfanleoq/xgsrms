# 测试账号预置指南

> 新增账号 **`test-qz-b`**、**`test-bm-b`** 尚未写入数据库；**`test-qz`** 可能需要重置密码。  
> 密码规则见 [[系统角色及测试计划]]。

---

## 方式一：SQL 脚本（推荐，可重复执行）

### 1. 生成 SQL

在项目根目录（需本机 **JDK**）：

```powershell
Set-Location I:\cursorProjects\xgsrms
py -3 scripts\seed_test_users.py -o scripts\sql\mysql\xgs_seed_test_users.generated.sql
# 若 test-qz 密码已修复，仅预置 B 账号：
py -3 scripts\seed_test_users.py --skip-fix -o scripts\sql\mysql\xgs_seed_test_users.generated.sql
```

脚本会：

| 账号 | 动作 |
|------|------|
| `test-qz` | 若已存在 → 重置密码为 `test-qz@2026` |
| `test-qz-b` | 新建，**克隆 `test-qz` 的角色** |
| `test-bm-b` | 新建，**克隆 `test-bm` 的角色**，绑定**不同于 test-bm 的第二个部门** |

密码加密与 Jeecg `PasswordUtil` 一致（`scripts/java/JeecgPasswordHash.java`）。

### 2. 在服务器执行

```bash
# SSH 到 xgs-server 后（数据库名、账号按实际修改）
mysql -u root -p jeecgboot < /path/to/xgs_seed_test_users.generated.sql
```

或在 MySQL 客户端中粘贴执行。

### 3. 前置条件

| 项 | 要求 |
|----|------|
| 模板账号 | **`test-qz`、`test-bm` 必须已存在**且角色正确 |
| 第二个部门 | `test-bm-b` 需要 **至少 2 个部门**；若只有 1 个，请先在界面新建「测试部门B」 |
| 备份 | 执行前备份 `sys_user` / `sys_user_role` / `sys_user_depart` |

### 4. 验证

```sql
SELECT u.username, u.realname, u.status, GROUP_CONCAT(r.role_name) roles
FROM sys_user u
LEFT JOIN sys_user_role ur ON ur.user_id = u.id
LEFT JOIN sys_role r ON r.id = ur.role_id
WHERE u.username IN ('test-qz','test-qz-b','test-bm','test-bm-b')
GROUP BY u.username, u.realname, u.status;
```

浏览器分别登录，确认图形验证码 + 密码可用。

## 方式二：系统管理界面（admin）

使用 **`admin` / `zktw@2019`** 登录后台 `http://10.28.12.15/`。

### A. 修复 test-qz

1. **【系统管理】→【用户管理】**，搜索 `test-qz`
2. 若不存在 → **新增**；若存在 → **编辑**
3. 姓名：求职者测试账号；密码：`test-qz@2026`；状态：正常
4. **角色**：与现有求职者账号相同（可复制 `test-qz` 已绑角色，或选「求职者」类角色）
5. 保存

### B. 新建 test-qz-b（求职者 B / IDOR）

| 字段 | 值 |
|------|-----|
| 登录名 | `test-qz-b` |
| 姓名 | 求职者测试账号B |
| 密码 | `test-qz-b@2026` |
| 角色 | **与 `test-qz` 完全相同**（在角色管理中对照勾选） |
| 部门 | 与求职者一致（通常可不绑后台部门） |

### C. 新建 test-bm-b（部门 B / IDOR）

| 字段 | 值 |
|------|-----|
| 登录名 | `test-bm-b` |
| 姓名 | 部门测试账号B |
| 密码 | `test-bm-b@2026` |
| 角色 | **与 `test-bm` 完全相同** |
| 部门 | **必须不同于 `test-bm` 所属部门**（选另一个一级/二级部门） |

若尚无第二个测试部门：

1. **【系统管理】→【部门管理】→ 新增**，例如「测试部门B」
2. 再创建 `test-bm-b` 并绑定该部门

### D. 对照复制技巧

1. 打开 `test-qz` / `test-bm` 用户详情，记下 **已选角色、部门**
2. 新建 B 账号时逐项对齐；**仅部门在 test-bm-b 上必须换绑**

## 与自动化测试的关系

预置完成后：

1. 更新 `docs/系统角色及测试计划.md` 中账号状态为 ✅  
2. 执行 E2E / Authz 前用各账号手工登录一次

## 故障排查

| 现象 | 处理 |
|------|------|
| SQL 执行后 `test-qz-b` 角色数为 0 | 模板 `test-qz` 不存在或无角色，先修复模板账号 |
| `test-bm-b` 部门数为 0 | 新建第二个部门后重跑 SQL 或界面改绑部门 |
| 登录仍失败 | 检查 `status=1`、`del_flag=0`、密码是否含特殊字符、账号是否被锁 |
| SQL 报 `Unknown column 'post'` | 已修复：重新生成 SQL（`seed_test_users.py` 已去掉 `post` 列） |
